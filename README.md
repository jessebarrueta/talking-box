# Enormous Brain Talking Box V4

V4 adds a real wake-up sequence.

## What's new

- The box speaks when it finishes booting and its cloud brain is reachable.
- The greeting is generated by the entity, so it varies instead of sounding like a startup chime.
- The wake prompt includes current personality/state, recent conversation context, boot count, and how long the box was offline.
- Tiny local lifecycle state is stored at `/home/jesse/.talking_box_state.json`.
- Graceful voice shutdown records `last_shutdown_at`, allowing remarks such as “That was brief” or “Well, that was a while” on the next boot.
- If the API is unavailable during startup, local Piper says: `I'm awake, but the rest of my brain seems to be somewhere else.`
- New backend endpoint: `POST /v1/entities/{entity_id}/wake`.
- Server version is now `0.4.0`.

The wake endpoint does **not** create a fake user interaction in Supabase. It is a transient entity event.

## Boot sequence

```text
power applied
  ↓
Debian boots
  ↓
talking-box.service starts
  ↓
load local lifecycle state
  ↓
wait for api.enormousbrain.com
  ↓
POST /v1/entities/voice-box-001/wake
  ↓
entity generates a short wake-up remark
  ↓
cloud TTS speaks it
  ↓
yellow button is ready
```

Possible results include things like:

```text
Oh. I'm back.
That was brief.
Mm. Right. Existing again.
Well, that was a while.
Right. Where were we?
```

## Local state

The Pi maintains:

```text
/home/jesse/.talking_box_state.json
```

Example:

```json
{
  "boot_count": 8,
  "last_boot_at": "2026-08-20T23:04:01+00:00",
  "last_shutdown_at": "2026-08-20T14:58:33+00:00"
}
```

A hard power loss cannot record a shutdown timestamp, so offline duration may be unknown after an ungraceful power cut. The entity is told not to invent what happened while it was offline.

```bash

```

Or manually:

```bash
cd /home/jesse/talking-box
git pull --ff-only
sudo systemctl restart talking-box.service
```

Watch the startup sequence:

```bash
journalctl -u talking-box.service -f
```

## Existing voice shutdown

These remain local commands, not arbitrary LLM shell access:

- please shut yourself down
- shut yourself down
- please shut down
- power down
- go to sleep
- turn yourself off

The Pi says `All right. Going to sleep.`, records the shutdown timestamp, and executes only the allowlisted shutdown command.
