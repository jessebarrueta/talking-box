# Talking Box V7.3 — Identity, Relationships & Disclosure

This patch adds **probable identity** and **relationship-aware disclosure**.

A probable match is a conversational hypothesis, not authentication. Jerry may say something like “I think that's Jesse—is that you?”, but probable identity does not unlock private memories, guardian-only information, or the verified-recipient mailbox.

Raw conversation history stays private by default. Cross-person disclosure happens through deliberately scoped memories or queued social messages.

## Apply

From the `talking-box` repository root:

```bash
python3 /path/to/apply_v7_3_identity_relationships.py
python3 -m py_compile server/main.py server/epistemics.py pi/talking_box.py pi/speaker_identity.py
python3 -m unittest tests.test_epistemics -v
git diff --check
git diff
```

## Private relationship data

Actual relationships are read from:

```text
~/.talking_box_relationships.json
```

The repo only gets a generic example. Relationship types can include `parent`, `child`, `sibling`, `spouse`, `partner`, `guardian`, `household`, `friend`, and `coworker`.

`parent` is deliberately **not** silently promoted to `guardian`.

## Probable identity defaults

```text
TALKING_BOX_SPEAKER_PROBABLE_THRESHOLD=0.50
TALKING_BOX_SPEAKER_PROBABLE_MARGIN=0.10
TALKING_BOX_SPEAKER_PROBABLE_RECENT_SECONDS=180
```

The recognizer also reports `best_sample_similarity` for diagnostics, but keeps the existing centroid score and verified threshold for actual recognition.
